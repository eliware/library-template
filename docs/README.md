# Library documentation

This directory explains how to use the sample API and adapt this repository.

> After you create a repository from this template, replace these documents with accurate end-user documentation for that library.

## Documents

- Read [Usage](usage.md) to run the example and use a derived library.
- Read [API reference](api.md) for the exported function, its input, and its result.

## Template status

This template provides sample source code. The `@eliware/library-template` package is not available from npm.
Create a derived library and replace the template package name before you publish or install that library.

## Validation

Run `npm test` to check the source, tests, documentation, package, and repository rules.
Run `npm run typecheck` to check the TypeScript declaration.
Run `npm run pack` to check the files that npm will include in a package.
