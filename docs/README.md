# Library documentation

This directory explains the sample API and how to adapt this template.

> After you create a repository from this template, replace these documents with complete and accurate end-user documentation for the derived library.

## Start here

- Read [Usage](usage.md) to create, validate, and publish a derived library.
- Read [API reference](api.md) for the sample package export and its behavior.

## Template status

This repository provides a sample library. The `@eliware/library-template` package is not published on npm. Create a derived repository and set its package name before you install or publish the derived package.

## Validate changes

Run commands from the repository root.

- Run `npm test` to check the repository with `eliware-test`.
- Run `npm run typecheck` to check the TypeScript declaration.
- Run `npm run pack` to check the files included in the npm package.
