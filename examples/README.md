# Examples

The [basic.mjs](basic.mjs) example shows the sample greeting output.

> After you create a repository from this template, replace these examples with examples for the derived library.

## Prerequisites

Use Node.js 26 or later in an ESM project.
The `@eliware/library-template` package is not published on npm.
Run the example from the repository root to use the local source.

## Command

Run `node examples/basic.mjs` from the repository root.

## Expected result

The example prints `Hello, Eli!`.
